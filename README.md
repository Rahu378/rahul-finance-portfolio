# Rahul Reddy CH · Financial Analyst

Personal portfolio: FP&A and business analysis, financial systems and compliance automation.

React 19, Vite, Tailwind CSS v4, Framer Motion and Recharts. Every fact on the site comes from
`src/data/profile.ts`; edit that one file to update content.

## Pages

- **Home**: a sample reconciliation monitor, four sourced metrics, and a scroll-driven trade lifecycle.
- **About**: operating principles, engagement process, a short operations quiz, certifications, leadership and education.
- **Skills**: every competency with search, category filters, a chart view and a detail drawer (⌘K also searches them).
- **Experience**: each role told as a stakeholder conversation, with a résumé mode.
- **Projects**: FinSight Agent (a structuring-detection lab), Text2Workflow (plain English to swimlane, exportable SVG) and the FP&A capstone (a four-scenario driver model).
- **Impact**: a live report with cross-highlighting and a draggable price-volume-mix bridge.
- **Contact**: composes an email draft in the visitor's own mail app; nothing is stored.

Charts marked "Sample data" are illustrative. The KPIs come from the résumé.

## Run

```bash
npm install
npm run dev
```

Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
